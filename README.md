# HabitZen

Привычки, фокус и маленькие победы. Будущее мобильное приложение по согласованному макету: привычки на день, календарь, таймер 25/5, растущее дерево, анимации, напоминания, звуки природы и смена языка.

**HZ-02: работает первый запуск по кадру 01.** Пять вводных страниц, светлая и тёмная темы, ru/uk/en с сохранением выбора, анимации и сценарий разрешения уведомлений. «Начать» и «Уже есть аккаунт» намеренно отключены. Остальные 11 кадров, аккаунты и запись привычек — следующие этапы.

Запуск: `npm ci`, затем `npm run web -- --port 8097` из корня. Открыть `http://localhost:8097`. Подробности — `docs/hz02-first-launch.md`.

## Проверки

Нужны Node 24, npm 11 и Docker для отдельной проверки PostgreSQL.

```powershell
npm ci
npm run check
npm run db:verify
npm run logs:demo
```

`db:verify` создаёт собственный временный PostgreSQL, применяет миграции и удаляет только свой контейнер. Окружение Telegram-бота не используется.

Все тесты хранятся отдельно в `tests/`: `unit`, `database`, `e2e`, `native`. Результаты и снимки — в `storage/reports/` вне Git. Подготовка браузера и команды — `tests/README.md`.

Полный локальный Supabase позже запускается `npm run db:start` и останавливается `npm run db:stop`. Он создаёт Docker volumes; остановка не означает удаление данных. Команда `npm run db:migrate` применяет миграции только к локальному экземпляру. Настройка: `docs/development.md`.

## Выбранная основа

React Native + Expo Router + TypeScript; NativeWind и Reanimated; Supabase с PostgreSQL, Auth и миграциями. Локальный серверный контур — Docker через Supabase CLI. Это соответствует разрешённой в общем задании альтернативе Convex.

Микросервисы, Redis и собственная система авторизации сейчас не нужны. Расширение сервера возможно через существующие контракты без переписывания экранов.
