# 🚀 Фінальні проєктні роботи з React Native (Prostir / PV411)

Цей каталог містить **10 комплексних практичних проєктних завдань** для студентів курсу з мобільної розробки на **React Native + Expo**.

Кожен проєкт є повноцінним мобільним застосунком, що поєднує сучасний стек технологій:
- **Навігація:** Expo Router (Tabs, Stacks, Modals, Dynamic Routes).
- **Стилізація:** NativeWind (Tailwind CSS) + темна/світла тема.
- **Бекенд у реальному часі:** Convex (Auth, Queries, Mutations, Storage) або Firebase/Supabase.
- **Анімації та фізика:** `react-native-reanimated` (v3/v4).
- **Жести та взаємодія:** `react-native-gesture-handler`.
- **Нативні можливості пристрою:** Камера, геолокація, аудіо, тактильний відгук (Haptics), пуш-сповіщення.

## 🎯 Правила вибору та роботи над проєктом

1. **Команда:** Проєкт може виконуватися індивідуально або в парі (2 студенти). Для пар обов'язковим є виконання розділу «Бонусні завдання підвищеної складності».
2. **Контроль версій:** Розробка ведеться у власному репозиторії GitHub з регулярними та змістовними комітами (`feat:`, `fix:`, `style:`).
3. **Демонстрація:** Фінальний проєкт повинен містити README з описом, скріншотами або GIF/відео роботи на реальному пристрої чи емуляторі.

## 📊 Критерії оцінювання (100 балів + 15 бонусів)

| Блок | Що оцінюється | Бали |
|---|---|:---:|
| **1. Архітектура та функціонал (MVP)** | Повнота реалізації екранів за специфікацією, валідація форм, коректна робота з бекендом (CRUD, Auth) | **40** |
| **2. Анімації (Reanimated 3/4)** | Використання worklet-стилів (`useAnimatedStyle`), пружинних та часових функцій (`withSpring`, `withTiming`, `withRepeat`) | **25** |

| **4. UI/UX та нативні модулі** | Адаптивність NativeWind, теми, робота з Haptics, Камерою, Звуком чи Локацією, стан завантаження/помилок | **20** |
| **★ Бонусний рівень** | Реалізація складних бонусних фіч із опису проєкту, додаткові мікроанімації, офлайн-кеш | **+15** |
