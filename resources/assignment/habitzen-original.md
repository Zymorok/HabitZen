# Проєкт 06: HabitZen — Гейміфікований трекер звичок і фокусу

## 📌 Опис та концепція проєкту
**HabitZen** — це естетичний та розслаблюючий застосунок для щоденної самодисципліни (читання, медитація, спорт, пиття води, вивчення англійської). Додаток поєднує трекінг щоденних ритуалів, таймер глибокого фокусу (Pomodoro) та віртуальне «дерево звичок», яке зеленіє та росте кожного дня, коли користувач закриває свій план.

Головний фокус проєкту — унікальні мікроінтеракції: **Hold-to-Complete** (затискання для підтвердження дії), дихальні анімації та пружні графіки стріків.

---

## 🛠 Технологічний стек
- **Фреймворк:** React Native (Expo SDK 52+)
- **Маршрутизація:** Expo Router (Tabs, Stacks, Modals)
- **Стилізація:** NativeWind v4 (Tailwind CSS, заспокійливі пастельні / темні тони)
- **Бекенд:** Convex (збереження звичок, історія виконання за датами)
- **Анімації:** `react-native-reanimated` (v3/v4)
- **Жести:** `react-native-gesture-handler` (LongPress, Pan)
- **Нативні API:** `expo-haptics` (наростаюча вібрація при затисканні), `expo-notifications` (щоденні нагадування)

## 🗄 Схема бази даних (Convex `schema.ts`)

```typescript
import { defineSchema, defineTable } from "convex/server";
import { v } from "convex/values";

export default defineSchema({
  users: defineTable({
    name: v.string(),
    email: v.string(),
    treeLevel: v.number(), // рівень зростання дерева від 1 до 10
    totalCompleted: v.number(),
  }),

  habits: defineTable({
    userId: v.string(),
    title: v.string(),
    icon: v.string(), // "water" | "book" | "fitness" | "meditation"
    color: v.string(), // Hex-код кольору картки
    targetDaysPerWeek: v.number(),
    streakCount: v.number(),
    bestStreak: v.number(),
    createdAt: v.number(),
  }),

  habitLogs: defineTable({
    habitId: v.id("habits"),
    dateString: v.string(), // "2026-10-03" (для швидких індексів)
    completedAt: v.number(),
  }),
});
```

## 🎯 Обов'язковий функціонал (MVP)

1. **Керування звичками:**
   - Створення нової звички (вибір категорії, іконки та кольору).
   - Відображення списку звичок на поточний день із прогрес-баром загального виконання (наприклад: 3 з 5 виконано).
2. **Щоденний чек-ін:**
   - Позначення звички як виконаної на сьогодні.
   - Автоматичний перерахунок серії днів (стріку). Якщо пропущено день — стрік скидається.
3. **Pomodoro Таймер:**
   - Таймер на 25 хвилин фокусу та 5 хвилин відпочинку.
   - Можливість призупинити, скинути або достроково завершити сесію.
4. **Календар активності:**
   - Перегляд календаря за поточний місяць, де дні фарбуються в зелений відтінок залежно від % виконаних звичок.

## 💫 Анімації та жести (Reanimated & Gesture Handler)

### 1. Hold-to-Complete з тактильним відгуком (Gesture.LongPress)
- **Суть:** Замість випадкового швидкого тапу, користувач має затиснути кнопку звички на 1.2 секунди.
  - Навколо кнопки плавно наростає круговий SVG-прогрес від `0%` до `100%` (`withTiming`);
  - Під час затискання що 200 мс спрацьовує легкий `Haptics.impactAsync(Light)`;
  - По досягненні 100% спрацьовує сильний `Haptics.notificationAsync(Success)`, кнопка видає пружний спалах `scale: 1.15 -> 1.0`, а картка стає напівпрозорою з закресленим текстом.

### 2. Дихальне розслаблююче коло (Breathing Animation)
- **Суть:** На екрані таймера коло розміром 180px плавно розширюється до 240px за 4 секунди (вдих) і плавно стискається за 4 секунди (видих) через `withRepeat(withSequence(...), -1)` з плавною кривою `Easing.inOut(Easing.ease)`.

### 3. Вогник стріку з пружним підстрибуванням (Streak Flame Bounce)
- **Суть:** Коли стрік збільшується, іконка вогника робить подвійне пружне підстрибування вгору зі зміною кольору з сірого на яскраво-помаранчевий.

### 4. Анімація росту дерева
- **Суть:** Ілюстрація дерева/рослини в хедері змінює свій вигляд і плавно «проростає» новими гілками/листям при накопиченні балів.
