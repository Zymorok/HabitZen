# Ресурсы первого запуска

Исходный согласованный коллаж — reference.png. Дополнительные референсы: hz02-welcome-detail.png и hz02-permission-flow.png. Они используются для сравнения, не показываются целиком внутри приложения.

Мир первого запуска нарисован отдельными прозрачными слоями: так код качает листья, траву и камыши по отдельности и двигает слои с разной скоростью. Текст, значки, кнопки, небо, солнце, луна, звёзды, свет и тени — средствами приложения. Колокольчик окна разрешений — отдельный рисунок в apps/mobile/assets/illustrations.

| Группа          | Файлы (apps/mobile/assets/onboarding, WebP)                                                       | Как используются                                                                |
| --------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Панорамы        | mountains_day/night, hills_day/night                                                              | Дальние слои параллакса; ночные варианты нарисованы отдельно, окна домика горят |
| Объекты страниц | sprout_leaves + sprout_mound, garden_bed, lake, hill_rocks + tree + sapling, path_bench + lantern | Главные объекты пяти страниц                                                    |
| Мелочи          | grass_1–3, flowers_1–2, bush, reeds, cloud_1–3, butterfly_1–2, leaf_green/orange, seed            | Качаются, плывут, летают и падают                                               |
| Волк и скала    | wolf_walk_1–2, wolf_sit, wolf_howl, wolf_sleep, rock                                              | Ночная история на скале                                                         |

Росток, скала и образец волка взяты из одобренных ракурсов (Desktop\HabitZen-3D). Росток разделён по цвету на листья и холмик. Ночью мелкие предметы темнеют и получают лунную кромку кодом.

Как перерисовать: сырые картинки складываются в Desktop\HabitZen-Art\сырые, затем `py prepare_layers.py split` (проверить разрезанные листы) и `py prepare_layers.py export` — скрипт обрезает поля, убирает случайные точки фона, делает панорамы плотными ниже хребта, сохраняет WebP и пересоздаёт world/art.ts.

## Шрифты

Lora 600/700 и Manrope 400/500/600 загружаются локально из @expo-google-fonts. Лицензии OFL сохранены в resources/licenses. Импорты отдельных начертаний исключают лишние шрифты из экспорта.
