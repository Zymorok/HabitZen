# Будущие проверки на устройстве

HZ-02: навигация, ru/uk/en, тёмная тема, крупный текст и первый запуск.
HZ-03: вход/выход, реальный Auth, два аккаунта, повтор запросов, ограничения доступа.
HZ-04: создание/редактирование/архив, удержание/отмена жеста, свайп и сбои сохранения.
HZ-05: таймер после сворачивания/перезапуска, пауза, звук, история и границы дней.
HZ-06: награда один раз, рост дерева, разрешения, напоминания после смены языка/пояса.
HZ-07: отдельные Android/iOS-прогоны и снимки каждого кадра макета.

Исполняемые сценарии HZ-02: onboarding.spec.ts. Конфигурация: playwright.config.ts. Из корня: сначала `npm run web -- --port 8097`, затем `npm run test:e2e` в другом терминале. Результаты и снимки — storage/reports/e2e. Настоящий диалог ОС проверяется отдельно в tests/native; браузер не заменяет проверку Android/iOS.
