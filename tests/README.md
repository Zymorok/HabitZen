# Отдельное дерево проверок

Все исполняемые тесты находятся здесь, отдельно от экранов и правил приложения.

```text
tests/
├── unit/                 # Быстрые проверки правил, языка, хранения и разрешений
├── database/             # Миграции, ограничения и изоляция данных PostgreSQL
├── e2e/                  # Поведение настоящего интерфейса в браузере
│   ├── playwright.config.ts
│   └── onboarding.spec.ts
└── native/               # Воспроизводимые проверки Android и список проверок iOS
```

- `npm test` — быстрые тесты, без устройства и БД.
- `npm run db:verify` — отдельный временный PostgreSQL в Docker.
- `npm run test:e2e` — интерфейс; сначала запустить `npm run web -- --port 8097`.
- `npm run check` — типы, стиль, форматирование, быстрые тесты, граница ядра.

Снимки, JSON-отчёты и следы прогонов сохраняются в `storage/reports/`, а не рядом с тестами. Эта папка не попадает в Git. `apps/mobile/android` и `ios` — генерируемые платформенные проекты, тесты приложения туда не переносятся.

Для первого запуска браузерных тестов: `npx playwright install chromium`. Можно задать `HABITZEN_CHROMIUM_PATH` для установленного Chromium и `HABITZEN_BASE_URL` для другого адреса приложения. Персональные пути в код не зашиты.

Проверка готовой сборки: `npm run export:web`, затем `npm run preview:web -- --port 8098`. Перед тестами задать `HABITZEN_BASE_URL=http://localhost:8098`. Этот вариант использован для финального прогона HZ-02.
