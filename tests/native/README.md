# Проверки на телефоне

Здесь хранятся воспроизводимые сценарии платформы. Исходники приложения не содержат файлов тестов. Браузерные тесты — в ../e2e, общие правила разрешений — в ../unit/permission-service.test.ts.

Android: собрать `npm run android --workspace @habitzen/mobile -- --port 8097` на отдельном эмуляторе. Проверить:

1. Первый запуск без внезапного запроса уведомлений; выключенные кнопки аккаунта.
2. Язык и тема, перезапуск процесса и сохранение выбора.
3. Перелистывание, безопасные отступы, возврат из окон.
4. «Не сейчас» без обращения к ОС.
5. Явное разрешение → настоящий системный диалог → отказ → спокойное объяснение.
6. После отказа → настройки ОС; возврат перечитывает статус.
7. Согласие → подтверждение; повторное открытие без нового системного запроса.
8. Анимация в активном приложении, остановка в фоне и при уменьшении движения; увеличенный системный шрифт.

Результаты и снимки: storage/reports/native. Сброс разрешений допустим только у собственного тестового app.habitzen.mobile. Не менять данные или разрешения других приложений.

iOS: отдельная сборка/устройство нужны для safe area, VoiceOver, системного диалога и тихого разрешения. Проверка Android не считается проверкой iOS. Точный статус текущего прогона — docs/verification.md.

Помощник: `node tests/native/android-probe.mjs launch home`, `tap-id language-button`, `tap-id language-option-ru`, `tap-id sheet-close`, `snapshot welcome`. Он сохраняет PNG и XML окна в storage/reports/native. ADB берётся из ANDROID_HOME или HABITZEN_ADB_PATH, устройство — HABITZEN_DEVICE (по умолчанию emulator-5554). Перед запуском приложение должно быть установлено, а Metro доступен телефону. Программа не сбрасывает данные и разрешения.

Для стабильного XML-прогона на одноразовом эмуляторе включалось уменьшение движения (transition_animation_scale=0), после прогона значение возвращается. Предупреждение Reanimated существует только в dev-сборке; его всплывающее окно нужно закрыть перед нажатиями. Программа отказывается использовать старый или пустой XML.

При сервере только на localhost в Windows Node может выбрать IPv6, а adb reverse подключается по IPv4. В этом прогоне Metro использует `NODE_OPTIONS=--dns-result-order=ipv4first`, порт 8097; хост собственного debug-приложения — localhost:8097. Сетевые настройки Windows не изменялись.
