# Принятые решения

| Решение                                  | Причина                                                                                              |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Один Expo-клиент и Supabase/PostgreSQL   | Соответствие заданию и нужные серверные возможности без второго backend                              |
| Docker через Supabase CLI                | Поддерживаемый локальный контур, миграции и отдельные тома                                           |
| npm workspaces и четыре маленьких пакета | Общие правила, дизайн, локализация и диагностика без раннего усложнения                              |
| История как планы дня и снимки           | Изменение привычки не переписывает прошлое                                                           |
| Версия строки + requestId                | Повторные запросы и два устройства не удваивают действие                                             |
| Все существенные записи через RPC        | Нельзя подделать счётчик, владельца или время выполнения прямой записью                              |
| ru/uk/en + system                        | Смена языка — общая возможность, а не отдельные строки в настройках                                  |
| Счётчики производные                     | Источник истины — подтверждённые действия                                                            |
| Собственная песочница на телефоне        | Серверный путь storage нельзя использовать как путь Android/iOS                                      |
| Поэтапная реализация экранов             | Структура не выдаётся за завершённое приложение                                                      |
| Живой 2D-мир вместо 3D (18.10.2026)      | Проба 3D-сцен: модели удались, но автоскелет волка непригоден. Слои дают глубину без тяжёлого движка |
| Отдельные прозрачные слои                | Код качает листья, траву и камыши по отдельности, а не всю картинку                                  |
| Ночь: свои панорамы + затемнение кодом   | Горы и холмы нарисованы ночными; мелкие предметы темнеют и получают лунную кромку                    |

Исследование Telegram-Bot выполнено только для организации кода, логов и хранения. Его рабочие процессы и данные не изменялись.

Пока не выбирались: сервер и тариф для публикации, платные сервисы, точные финальные шрифты, провайдер резервных копий и дополнительные языки. Они не мешают завершить основу.
