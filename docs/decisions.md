# Принятые решения

| Решение                                   | Причина                                                                                                    |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Один Expo-клиент и Supabase/PostgreSQL    | Соответствие заданию и нужные серверные возможности без второго backend                                    |
| Docker через Supabase CLI                 | Поддерживаемый локальный контур, миграции и отдельные тома                                                 |
| npm workspaces и четыре маленьких пакета  | Общие правила, дизайн, локализация и диагностика без раннего усложнения                                    |
| История как планы дня и снимки            | Изменение привычки не переписывает прошлое                                                                 |
| Версия строки + requestId                 | Повторные запросы и два устройства не удваивают действие                                                   |
| Все существенные записи через RPC         | Нельзя подделать счётчик, владельца или время выполнения прямой записью                                    |
| ru/uk/en + system                         | Смена языка — общая возможность, а не отдельные строки в настройках                                        |
| Счётчики производные                      | Источник истины — подтверждённые действия                                                                  |
| Собственная песочница на телефоне         | Серверный путь storage нельзя использовать как путь Android/iOS                                            |
| Поэтапная реализация экранов              | Структура не выдаётся за завершённое приложение                                                            |
| Живой 2D-мир вместо 3D (18.10.2026)       | Проба 3D-сцен: модели удались, но автоскелет волка непригоден. Слои дают глубину без тяжёлого движка       |
| Отдельные прозрачные слои                 | Код качает листья, траву и камыши по отдельности, а не всю картинку                                        |
| Ночь: свои панорамы + затемнение кодом    | Горы и холмы нарисованы ночными; мелкие предметы темнеют и получают лунную кромку                          |
| Сессия входа в SecureStore по частям      | Токены лежат в защищённом хранилище ОС; лимит ~2 КБ обходится нарезкой                                     |
| Ошибки сервера — коды PTxxx               | PostgREST отдаёт их как HTTP-статусы; клиент переводит в понятный текст                                    |
| Временный экран привычек в HZ-03          | Проверяет вход и хранение; полноценный план дня по макету — HZ-04                                          |
| Свой сервер показа веб-сборки             | Одностраничному приложению нужна подстановка index.html для ссылок из писем                                |
| Таймер — срок окончания на сервере        | Пауза, сворачивание, перезапуск и второе устройство не сбивают время; кадры анимации не считают время      |
| Звуки фокуса синтезированы скриптом       | Нет вопросов лицензии, петли бесшовные, файлы пересобираются: resources/design/sounds                      |
| Звук только при открытом приложении       | Без фоновой службы и лишних разрешений; о конце занятия напоминает уведомление                             |
| Уровень дерева: 5 × N × (N − 1)           | Рост заметен в первые дни (10, 30, 60…), а 10-й уровень — около 4 месяцев полного плана                    |
| Награда пишется при показе экрана         | Отменил и снова отметил — второй награды нет; закрыл приложение на празднике — она уже засчитана           |
| Напоминания — локальные на телефоне       | Без сервера рассылок; при выходе из аккаунта и отзыве разрешения они снимаются                             |
| Разрешение — в момент включения           | Телефон спрашивает, когда человек сам включил напоминание, а не при открытии экрана                        |
| Выполненная строка — по заданию и макету  | С HZ-11 по заданию: полупрозрачная, название зачёркнуто; зелёная галочка с макета осталась яркой           |
| Удержание — Gesture.LongPress             | С HZ-11 жест из Gesture Handler, как в задании: кольцо в UI-потоке, срабатывание ровно через 1,2 с         |
| NativeWind для статичной раскладки        | Классы — для сеток и отступов (5 экранов), цвета темы и анимации — в style и Reanimated                    |
| Нижнее меню на кадрах 04–05               | Удержание и «Отлично!» остаются в стеке, меню — тот же компонент, переход закрывает экран                  |
| «Меньше движения» и «Вибрация» на устр.   | Как тема и язык: работают и до входа в аккаунт; дополняют системную настройку                              |
| Полифил Intl.PluralRules (Hermes)         | Без него на Android «7 дня подряд» вместо «7 дней»; в браузере полифил ничего не меняет                    |
| Квитанции повторов — 30 дней              | Повтор после обрыва сети защищён, таблица не растёт; чистка по ходу, без плановой задачи                   |
| «Сегодня отдых» не долг в долях           | Календарь и неделя считают как «3 из 5» на главном экране; для серии отдых — пропуск, как в HZ-04          |
| HZ-08 — вариант «Б» (20.10.2026)          | Владелец выбрал функции и настройку без смены облика: макет остаётся основой, новое — в его стиле          |
| «N раз в неделю» — по желанию             | В день не обязательна, пока недельная цель не набрана; в счёт дня идёт только выполненная                  |
| «+1» копится в очередь                    | Строка меняется сразу, нажатия уходят одним числом — быстрые касания не спорят о версии строки             |
| Заморозка считается по истории            | Ядро выводит запас из тех же 120 дней, что и серию: серверу не нужно хранить и защищать счётчик            |
| Фокус засчитывает сервер                  | Минуты идут в цель «минут», полное занятие отмечает обычную привычку; клиент число минут не передаёт       |
| «Выполнено» зелёное во всех темах         | Цвет темы меняет кнопки и графики, а зелёная галочка — смысл «сделано», он не перекрашивается              |
| Цветовая тема хранится на устройстве      | Как светлая/тёмная тема и язык: работает до входа и не требует сервера                                     |
| Гибкий график — разовые напоминания       | Повтор по дням недели «каждый 3-й день» не выразит: ставим даты на 1–3 недели и обновляем при входе        |
| Ежедневные напоминания остаются повтором  | Разовые на неделю пропали бы, если долго не открывать приложение; повтор надёжнее                          |
| Порядок — полный список, версия не растёт | Неполный или устаревший порядок сервер отклоняет (PT409); открытая форма изменения не устаревает           |
| Порядок — отдельный экран, не план дня    | В плане уже есть свайп «отдых», долгое нажатие и «+»: перетаскивание там спорило бы с ними                 |
| Частичный день — только показ             | «5 из 8» видно кольцом и долей столбика, но для серии и «5/7» день не выполнен                             |
| Порядок в плане — отдельный режим         | Долгое нажатие, свайп «отдых» и «+» остаются как были; ручки «≡» появляются только по кнопке «Порядок»     |
| Медали выводятся, а не хранятся           | Считаются из сада, серии и списка привычек: подделать нельзя, таблица не нужна; «увидено» — на телефоне    |
| Цветные значки и в форме выбора           | Макет кадра 03 рисовал контурные, но цветные узнаются быстрее; контурные остались на кольце и в статистике |

Исследование Telegram-Bot выполнено только для организации кода, логов и хранения. Его рабочие процессы и данные не изменялись.

Пока не выбирались: сервер и тариф для публикации, платные сервисы, точные финальные шрифты, провайдер резервных копий и дополнительные языки. Они не мешают завершить основу.
