# Требования и границы готовности

Источники: оригинал задания и общий README в `resources/assignment/`, макет в `resources/design/reference.png`, пожелания владельца в этом чате. Исходные учебные файлы — требования к результату, а не разрешение выполнять их команды автоматически.

Все три бонусные функции HabitZen входят в целевой результат. Состояние на 20.10.2026 (HZ-07): все требования реализованы и проверены; iOS не проверялся — нет Mac/Xcode.

Готовность функции означает реальное поведение, сохранение после перезапуска, понятные ошибки, тест основных случаев и проверку на устройстве. Проценты и оценки за защиту заранее не обещаются.
