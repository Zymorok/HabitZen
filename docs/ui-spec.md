# Интерфейс и движения по макету

Главный ориентир — `resources/design/reference.png`. Сохраняем ботанический стиль: тёплый светлый фон, лесной зелёный, мягкие карточки, небольшие персиковые акценты и рисованное дерево. Подгоняем реальные экраны по снимкам, а не используем коллаж как фон приложения.

Исходный макет — изображение 1536×1024 с 12 уменьшенными экранами, а не редактируемый макет с точными размерами. Первые токены приближённые. Для близкого повторения понадобятся отдельные иллюстрации дерева и фона, шрифты с кириллицей, иконки и сравнение каждого экрана в одном размере.

## Карта кадров

| Кадр             | Будущий маршрут                     | Что делает                                                |
| ---------------- | ----------------------------------- | --------------------------------------------------------- |
| 01 Первый запуск | /(onboarding)                       | Объяснение, выбор языка, вход или регистрация             |
| 02 План дня      | /(app)/(tabs)/today                 | Дерево, серия, прогресс и список привычек                 |
| 03 Создание      | /(app)/habit/new (?id= — изменение) | Название, категория, значок, цвет, дни и напоминания      |
| 04 Удержание     | /(app)/habit/[itemId]               | Прогресс удержания 1,2 с; отпускание раньше отменяет жест |
| 05 Выполнено     | /(app)/done                         | Подтверждённая отметка, новый прогресс, отмена            |
| 06 Фокус         | /(app)/(tabs)/focus                 | 25 минут, пауза, сброс, звук                              |
| 07 Перерыв       | Состояние того же focus             | 5 минут, начать или пропустить                            |
| 08 Календарь     | /(app)/(tabs)/progress              | Месяц, конкретный день и итоги недели                     |
| 09 О привычке    | /(app)/habit/stats/[habitId]        | История, серия и изменение привычки                       |
| 10 Дерево        | /(app)/(tabs)/garden (скрытая)      | Уровень, стадии роста и следующий рубеж                   |
| 11 День завершён | /(app)/celebration                  | Однократная награда после полного плана                   |
| 12 Настройки     | /(app)/(tabs)/profile, /reminders   | Профиль, язык, тема, напоминания и звук                   |

Дополнительные обязательные маршруты: вход, регистрация, подтверждение почты, восстановление, изменение привычки и выбор языка. Их нет на коллаже, но они нужны рабочему приложению.

## Компоненты

Общие: Screen, AppText, Button, Card, IconButton, BottomTabs, ProgressRing, EmptyState, ErrorState, Skeleton, ModalSheet. Тематические: HabitCard, HoldProgress, WeekdayPicker, BreathingCircle, MonthHeatmap, StreakBadge, GardenScene. Сложные компоненты принадлежат своей функции; общие кнопки не знают о базе и привычках.

Начальные размеры: ширина сравнения 390 dp, отступ экрана 24, минимальная область касания 48, радиус карточки 24. Serif для крупных заголовков и читаемый sans для остального: окончательные семейства выбираются вместе с лицензиями и проверкой ru/uk/en. Отступы учитывают системные панели и клавиатуру.

## Анимации

| Действие    | Поведение                                                                                |
| ----------- | ---------------------------------------------------------------------------------------- |
| Удержание   | Круг 0→100% за 1200 мс; преждевременное отпускание возвращает прогресс                   |
| Вибрация    | Лёгкая каждые 200 мс при удержании; одна итоговая после успеха; выключается в настройках |
| Успех       | Масштаб 1,15→1, зачёркивание/приглушение карточки; запись не повторяется от кадров       |
| Дыхание     | 180→240 dp за 4 с и обратно за 4 с; фаза одинакова для текста и круга                    |
| Серия       | Двойной мягкий прыжок и изменение цвета после подтверждённого роста серии                |
| Дерево      | Плавное появление листьев/ветвей при переходе уровня                                     |
| Награда     | Короткие частицы один раз на завершённый план; повторный вход не повторяет награду       |
| Свайп влево | Понятный фон и подпись «Сегодня отдых», без случайного срабатывания при прокрутке        |
| Смена темы  | Короткий переход без белого всплеска и сброса текущего экрана                            |

Движение идёт через Reanimated/shared values; React не обновляет весь экран на каждом кадре. Побочные действия — один раз на переход состояния. При сворачивании останавливаются декоративные циклы и звук по политике пользователя; таймер остаётся точным.

Системное уменьшение движения или настройка пользователя отключает циклы, крупные прыжки и частицы. Доступная альтернативная кнопка позволяет выполнить привычку без обязательного удержания при использовании экранного диктора.

## Соответствие

Для каждого экрана нужны состояния загрузки, ошибки, отсутствия данных, сохранения и слабой сети. Снимки сравниваются в одинаковых размерах, с теми же демонстрационными данными. Проверяются Android, iOS отдельно, три языка, тёмная тема и крупный шрифт.

У календаря на макете условная раскладка дат: приложение строит настоящий календарь, сохраняя стиль. Перевод не обрезается ради буквального совпадения картинки. Яркая зелёная галочка не показывается как окончательно сохранённая при неудаче запроса.
