# Рабочие данные HabitZen

Содержимое не попадает в Git. Исходники, настройки по умолчанию и ресурсы лежат вне этой папки.

- `logs/<дд.мм.гггг>/<уровень>/<runId>.jsonl` — события локальных инструментов и будущих серверных процессов; отдельный файл `all`.
- `reports/<запуск>/` — результаты проверок и отчёты миграций.
- `backups/` — выгрузки базы; только вне исходников, с ограниченным доступом.
- `exports/` — запрошенные пользователем выгрузки; будущая функция.
- `runtime/` — временные файлы запуска.
- `tmp/` — промежуточные файлы; удаляются только конкретным владельцем.

PostgreSQL локального Supabase хранится в Docker volumes под управлением CLI. Сырые файлы базы не копируются в эту папку и не монтируются как у Python-бота: для Supabase поддерживается собственный жизненный цикл. Резервная копия — проверенный дамп и отдельные объекты Storage, а не копирование каталога работающей БД.

В мобильном приложении — песочница Expo: SecureStore для секретов, SQLite для рабочего состояния и очереди, cache для временных ресурсов. NodeFileSink не импортируется в мобильную сборку.
