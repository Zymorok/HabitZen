# settings

Профиль, тема, язык, звуки и напоминания (кадр 12, HZ-06). Язык и тема меняются без перезапуска и хранятся на устройстве; звуки и напоминания — в аккаунте.

- `data/` — `user_settings` и имя профиля.
- `screens/SettingsScreen.tsx` — кадр 12, `screens/PreferencesScreen.tsx` — выбор языка и темы.
- `components/ThemePreview.tsx` — маленький экран в светлой и тёмной теме.
