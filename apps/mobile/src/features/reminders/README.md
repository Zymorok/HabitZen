# reminders

Локальные напоминания (HZ-R14): вечернее и по времени каждой привычки в её дни.

- `plan.ts` — что и когда напомнить, чистое правило (tests/unit/reminders.test.ts).
- `ReminderSync.tsx` — держит напоминания телефона в согласии с аккаунтом, языком и разрешением.
- `screens/RemindersScreen.tsx` — общий выключатель, вечернее время, привычки с напоминанием.
- Постановка на телефоне — `platform/notifications/reminders.*`; в браузере напоминаний нет.
