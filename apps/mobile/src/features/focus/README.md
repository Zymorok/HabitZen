# focus

Фокус 25 минут, перерыв 5 минут, пауза, восстановление, звук и дыхание (кадры 06–07, HZ-05).

- `data/` — команды таймера на сервере (`start_focus`, `pause_focus`, …) и выбранный звук.
- `screens/FocusScreen.tsx` — один экран для фокуса и перерыва; время — по сроку с сервера.
- `components/` — кольцо таймера и круг дыхания.
- Звук — `platform/audio/focus-audio.ts`, уведомление о конце — `platform/focus-alert/`.
